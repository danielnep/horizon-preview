Configuração Horizon

Conecte registros reais à sua planilha.

As demonstrações funcionam sem conexão. Este passo é separado e requer a sua conta Google e uma planilha.

Estado inicial: não conectado. Os exemplos da vitrine ficam no navegador. O teste de conexão grava apenas na aba Teste_Horizon.
  1. Crie uma planilha no Google Sheets. Copie o ID entre /d/ e /edit no endereço.
  2. Na planilha, abra Extensões → Apps Script.
  3. Copie o arquivo Code.gs para o editor. Substitua COLE_O_ID_DA_SUA_PLANILHA pelo ID.
  4. Confira allowedOrigins: ele deve conter o endereço exato em que a demonstração está hospedado, sem barra final. Acrescente outro endereço somente se você usar outra hospedagem.
  5. Para validar o recebimento de testes, use Implantar → Nova implantação → Aplicativo da Web. Execute como o proprietário e selecione o acesso disponível que permita o navegador que fará o teste. Autorize o acesso à sua planilha na conta Google.
  6. Copie a URL de implantação terminada em /exec. Na solução real, defina essa URL em CONFIG.googleSheetsUrl, no arquivo dist/config.js. A vitrine comercial não exibe configurações técnicas.
  7. Chame sendRealRecord com kind: teste na aplicação real. Considere a gravação confirmada apenas após a resposta válida. Confira a aba Teste_Horizon.
Sem confirmação, a gravação pode ter ocorrido. Confira a planilha antes de tentar novamente. O endpoint não faz autenticação de visitantes; a lista de origens orienta a resposta, mas não substitui controle de acesso. Antes de habilitar dados reais internos, escolha as permissões de implantação apropriadas à empresa.

Reutilize em uma solução real.

O adaptador é separado das demonstrações. Depois de validar permissões e conexão, habilite allowRealRecords no Apps Script e chame o adaptador somente ao confirmar um registro real. Nunca conecte os dados fictícios automaticamente.

import { sendRealRecord } from './integrations/google-sheets.js';

await sendRealRecord(URL_DA_IMPLANTACAO, {
  id: 'registro-empresa-0001',
  kind: 'real',
  title: 'Material recebido',
  owner: 'Responsável',
  quantity: 2,
  notes: 'Registro confirmado pela equipe.'
});

O mesmo ID atualiza a linha existente. Novos IDs criam novas linhas. Não coloque senhas nem chaves privadas no aplicativo.

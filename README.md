# Horizon Preview

Vitrine mobile-first de ferramentas empresariais combináveis. Branco, azul celeste e detalhes azul-prateados.

## Executar

Sirva `dist/` em qualquer servidor estático, ou abra `dist/index.html`. Nenhuma instalação, chave de API, conta ou infraestrutura paga é necessária.

## Ferramentas

Registros com CSV; serviços por etapa; conferências; agenda; indicadores ligados aos dados locais; atendimento simulado por intenção; extração textual por regras; diagnóstico simulado por palavras-chave; seleção combinada e solicitação preparada para WhatsApp.

Os cenários são fictícios. IA é explicitamente simulada localmente. Não há OCR de imagens, conexão com planilhas externas, notificações ou processamento por modelos de linguagem. Dados ficam no localStorage deste navegador. O número de destino do WhatsApp está pendente; a mensagem abre o compartilhamento sem destinatário fixo.

## Verificar

`node tests/engine.test.cjs`

Publicação estática definida em `.openai/hosting.json`. Repositório GitHub pretendido: `horizon-preview`; criação externa depende do login autorizado do proprietário.

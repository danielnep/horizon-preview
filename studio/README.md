# Horizon Studio
Fonte dedicada do Horizon Studio, mantida no repositório horizon-preview como solicitado pelo proprietário.
A pasta studio contém o frontend PWA, a API e o código dos serviços Studio; a demonstração original do repositório permanece intacta.
Para rodar isolado: cd studio && npm install && node server.mjs
A VPS é a origem das prévias dos aplicativos. O site institucional continua em danielnep/horizon-site.
Serviços do host e credenciais não são versionados neste repositório.
